# v0.2 설계 결정

## 1. 담당교사 Excel

Excel은 OCR이 아니라 셀 직접 파싱을 사용한다.
업로드 결과는 자동 저장하지 않고 미리보기 검증 단계를 통과해야 한다.

## 2. 날짜별 담당자

담당 여부는 `dutyAssignments/{yyyy-MM-dd}`의 `teacherUid`로 판정한다.
주간/월간은 UI와 Excel의 조회/입력 단위일 뿐 DB는 날짜별 단일 문서다.

## 3. 담임

`classes/{classId}`에 담임 UID/이름을 저장하고 `users/{uid}.homeroomClassId`를 함께 맞춘다.
한 교사를 다른 반에 지정하면 기존 반 연결을 해제한다.

## 4. 통계

v0.2는 원본 출결을 기간 조회한 뒤 클라이언트 집계한다.
학교 한 학년 규모에서는 충분하다. 실제 읽기 비용이 커질 경우 Cloud Functions로 주/월 집계를 생성해 캐시할 수 있다.

## 5. 출결 미입력

레코드가 없는데 UI만 출석으로 표시하면 통계가 틀리므로 `미입력`으로 표시한다.
담당교사는 `현재 반 전체 출석 처리` 후 예외 학생만 지각/결석/인정/조퇴로 변경하는 흐름을 사용한다.

## 6. 다운로드 권한

과거 출결 원본 Excel은 우선 학년부/최고관리자만 허용한다.
담임 다운로드가 필요하면 자기 반만 허용하는 서버 규칙을 추가한다.
