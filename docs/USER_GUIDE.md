# 자습 출결 시스템 사용 설명서

기준: `master` 코드(2026-11-12, PR #9까지 병합). 화면 이름과 버튼 이름은 실제 화면 문구를 그대로 적었습니다.
PR #10(담임 통계 학급 드롭다운 고정)이 병합되기 전에는 6장의 "담임 학급 드롭다운" 설명이 아직 적용되지 않습니다.

## 1. 누가 무엇을 할 수 있나

| 역할 | 정해지는 곳 | 할 수 있는 일 |
|---|---|---|
| 최고 관리자(시스템 소유자) | 계정 역할 | 모든 학년도·학년 관리, 교직원 승인과 배정, 통계 정책, 운영 모드, 학교 전체 예외일 |
| 학년부(학년 관리자) | 교직원 / 권한 관리에서 학년도·학년별 배정 | 그 학년의 학생·반·시간표·자습실·감독 배정·예외일 관리, 출결 보정, 이력·통계·감사 기록 조회 |
| 담임 | 학급 / 담임 관리에서 반마다 지정 | 자기 반 학생의 자습 예외(허락) 등록, 자기 반 이력 조회, 정책이 허용하면 자기 반 통계 |
| 일반 교사 | 학년 배정 | 감독으로 배정된 날짜·교시·자습그룹의 출결 입력 |

- 권한은 기본적으로 막혀 있습니다. 학년 배정이 없으면 로그인해도 업무 화면에 들어갈 수 없습니다.
- 감독 권한은 "그 날짜·그 교시·그 자습그룹"에만 생깁니다.
- 학년부·담임·감독은 학년도마다 따로 지정합니다. 새 학년도에 자동으로 넘어가지 않습니다.

## 2. 로그인과 계정 승인

1. 로그인 화면에서 **Google 계정으로 로그인**을 누릅니다. 등록된 교직원 Google 계정만 쓸 수 있습니다.
2. 처음 로그인하면 "교직원 계정 승인 대기 중입니다." 화면이 나옵니다. Google 인증만으로는 권한이 생기지 않습니다.
3. 최고 관리자가 **시스템 관리자** 화면의 "승인 대기 사용자"에서 **승인**합니다.
4. 이어서 **교직원 / 권한 관리**에서 학년도·학년 배정(일반 교사 또는 학년 관리자)을 추가해야 업무 화면이 열립니다.

## 3. 화면 공통

- 위쪽 **현재 범위**에서 학년도와 학년을 고릅니다. 대부분의 화면은 고른 학년만 다룹니다.
- 최고 관리자만 "전체 학년"을 고를 수 있습니다. 학생·반·자습 운영 같은 관리 화면은 특정 학년을 골라야 쓸 수 있습니다.
- 왼쪽 메뉴는 역할에 따라 다르게 보입니다. 권한이 없는 메뉴는 숨겨집니다.
- 운영 모드가 "조회 전용", "시스템 점검", "전체 접근 제한"이면 일반 사용자는 저장하거나 접속할 수 없습니다(9장 참고).

## 4. 학년 시작 준비 (최고 관리자 → 학년부)

순서대로 해야 다음 단계가 동작합니다.

1. **시스템 관리자 > 학년도 관리**: 새 학년도를 추가하고 **현재 학년도로 변경**합니다. 현재 학년도는 하나만 둘 수 있습니다.
2. **시스템 관리자 > 학년 관리**: 그 학년도에 학년(1·2·3학년)을 추가합니다.
3. **교직원 / 권한 관리**: 승인된 교직원을 학년마다 "일반 교사" 또는 "학년 관리자"로 배정합니다.
4. **학급 / 담임 관리**(학년부): 반을 만들고 담임을 지정합니다. 담임 후보는 그 학년에 배정된 교직원만 나옵니다.
5. **학생 명부**(학년부): 학생을 한 명씩 추가하거나 XLSX 명부를 가져옵니다.
   - 필수 열: 학년, 반, 번호, 학생 이름
   - **명부 미리보기**에서 오류를 모두 해결한 뒤 **확인 후 적용**을 누릅니다.
6. **자습 시간표 관리**(학년부): 요일마다 자습 시간과 점심/휴식을 만듭니다.
   - 요일별 시간표는 따로 저장됩니다. **현재 시간표를 월~금에 반영**을 눌렀을 때만 복사됩니다.
   - 점심·휴식은 출결·감독 대상이 아닙니다.
7. **자습그룹 / 자습실 관리**(학년부): 자습실·독서실을 만들고 다음 두 가지를 합니다.
   - **운영 교시**를 연결합니다. 연결하지 않으면 그 그룹에 감독을 배정할 수 없습니다.
   - **학생 자습실 배정**에서 학생을 그룹에 넣습니다. 학생의 반 소속은 바뀌지 않습니다.
8. **감독교사 배정**(학년부): 5장을 참고합니다.
9. **신학년도 준비 현황**(최고 관리자): 항목별 준비 상태를 확인하는 읽기 전용 화면입니다. 아무것도 자동으로 복사하지 않습니다.

## 5. 감독교사 배정 (학년부)

- 메뉴: **감독교사 배정**. **월 선택**으로 달을 고르고, **배정표**나 **월간 달력**으로 봅니다.
- 배정 방법은 두 가지입니다.
  - **직접 추가**: 날짜, 교시, 자습그룹, 감독교사를 고르고 **저장**합니다.
  - **Excel 업로드**: 열 이름은 `날짜`, `교시`, `자습그룹`, `감독교사`입니다. 교시·자습그룹·감독교사는 화면에 보이는 이름(또는 ID)으로 적습니다. 선택한 월 안의 날짜만 받습니다. **Excel 미리보기**에서 "저장 가능"을 확인한 뒤 **확인 후 저장**을 누릅니다.
- **미배정만 보기**로 빠진 칸을 찾습니다.
  - "미배정": 연결된 교시에 감독이 없는 상태입니다.
  - "교시 미연결": 그 자습그룹에 교시 자체가 연결되지 않은 상태입니다(4장 7번).
- 감독교사는 자기 일정을 **감독교사 일정** 메뉴에서 확인합니다.

## 6. 자습 출결 입력 (감독교사)

1. 메뉴 **자습 출결**을 엽니다.
2. **날짜**, **교시**, **자습 그룹**을 고릅니다. 내가 배정된 교시와 그룹만 나옵니다.
   - "이 날짜에 담당한 자습 운영이 없습니다."가 나오면 감독 배정을 학년부에 확인합니다.
3. 학생마다 **출석** 또는 **결석**을 누릅니다.
   - 결석을 누르면, 담임이 그 날짜에 자습 예외(허락)를 등록한 학생은 **인정 결석**, 아닌 학생은 **무단(미인정) 결석**으로 저장됩니다.
   - 아무것도 누르지 않은 학생은 **미입력**입니다. 미입력은 무단 결석으로 자동 처리되지 않습니다.
4. 대부분 출석이면 **전체 출석**을 누릅니다. 미입력 학생만 저장 대기 목록에 "출석"으로 들어갑니다. 결석 학생은 따로 바꿉니다.
5. 아래쪽 **저장 (n)** 버튼을 눌러야 실제로 저장됩니다. 저장하지 않고 날짜·교시·그룹을 바꾸면 경고가 나옵니다.
6. "출결 저장이 완료되었습니다."를 확인합니다. 실패하면 네트워크를 확인하고 다시 저장합니다.

입력할 수 있는 시간:
- 감독교사는 배정된 **그 날짜 하루 동안**(한국 시간 0시~23시 59분)만 입력·수정할 수 있습니다. 그 밖에는 "현재 담당 편집 시간이 아니므로 조회 전용입니다."가 나옵니다. (코드 기준이며 운영 환경에서는 아직 확인하지 않았습니다.)
- 시간이 지난 기록은 학년부나 최고 관리자가 같은 화면("관리자 출결 보정")에서 고칩니다.
- 자습 운영 예외일(공휴일·시험 등)로 막힌 날짜와 교시는 저장되지 않습니다.

## 7. 자습 예외(허락) 등록 (담임)

- 메뉴: **자습 허락**(화면 제목 "학생 자습 예외"). 자기 담임 반 학생만 보이고 바꿀 수 있습니다.
- 날짜를 고르고, 학생 줄에서 **예외 등록**을 누릅니다. **사유**(학원, 병원/의료, 가정사, 학교활동, 기타)와 **사유 상세**를 적고 **저장**합니다.
- 등록한 학생은 그날 감독교사가 결석을 누르면 인정 결석이 됩니다. 출결을 입력하기 **전에** 등록해 두는 것이 좋습니다.
- 잘못 등록했으면 **수정**하거나 **취소**합니다.
- "자습 그룹 미배정" 학생은 자습 대상이 아니므로 학년부에 배정을 확인합니다.

## 8. 조회: 이력, 통계, 감사 기록

**자습 출결 이력** (학년부, 담임)
- 기간, 교시, 반, 자습그룹, 학생, 상태로 걸러서 봅니다.
- 담임은 자기 반 기록만 볼 수 있습니다.
- **Excel 다운로드**를 받을 수 있습니다. 파일에는 학생 개인정보가 들어 있으니 보관과 공유에 주의합니다.

**자습 출결 통계** (학년부, 정책이 허용하면 담임)
- 기간은 일별, 주별, 월별, 사용자 지정 중에서 고릅니다.
- 집계는 전체, 학급별, 자습그룹별, 교시별, 학생별 중에서 고릅니다.
- "출결 상태 분포"에서 예상·출석·인정 결석·무단 결석·미입력 수를 봅니다.
- 담임 열람 여부는 최고 관리자가 **시스템 관리자 > 통계 열람 권한 > 정책 변경**으로 정합니다.
  - 기본값은 "학년부만"입니다.
  - "학년부 + 담임(본인 반)"으로 바꾸면 담임에게 통계 메뉴가 보이고 자기 반 통계만 나옵니다. 학급 드롭다운은 본인 반으로 고정됩니다(PR #10 병합 후).

**감사 기록** (학년부, 최고 관리자)
- 누가 언제 무엇을 바꿨는지 봅니다. 출결 저장, 감독 배정, 정책 변경 등이 남습니다.

## 9. 운영 모드와 점검 (최고 관리자)

메뉴는 **시스템 운영 / 비상 모드**입니다.

| 모드 | 일반 사용자 |
|---|---|
| 정상 운영 | 모든 기능 |
| 조회 전용 | 보기만 가능, 저장 불가 |
| 필수 자습 운영 | 필수 출결 기능만 |
| 시스템 점검 | 점검 안내만 표시 |
| 일반 사용자 접근 제한 (LOCKDOWN) | 접속 차단 |

- 최고 관리자는 모든 모드에서 계속 들어갈 수 있습니다.
- **예약 점검**을 켜면 안내 시작·점검 시작·점검 종료 시각과, 상단 배너·알림 표시 여부를 정할 수 있습니다.

## 10. 자주 생기는 문제

| 증상 | 확인할 것 |
|---|---|
| 로그인 후 "승인 대기" | 최고 관리자의 승인과 학년 배정 |
| 메뉴가 거의 없음 | 현재 범위의 학년도·학년, 그 학년 배정 여부 |
| 자습 출결에 그룹이 안 나옴 | 그 날짜·교시 감독 배정, 그룹의 운영 교시 연결 |
| 학생 목록이 비어 있음 | 학생 자습실 배정, 학생 활성 상태 |
| 저장 버튼이 안 눌림 | 편집 시간(배정된 날짜 당일), 운영 모드, 예외일 |
| 담임에게 통계가 안 보임 | 통계 열람 정책(기본 "학년부만"), 반의 담임 지정 |
